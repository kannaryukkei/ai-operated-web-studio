# Starter QA Checklist

## Build and code
- [ ] Dependencies install.
- [ ] Production build passes.
- [ ] Automated browser tests pass.
- [ ] No critical console errors or broken assets.

## Content
- [ ] Business identity, contact, location, offers approved.
- [ ] Prices and conditions confirmed.
- [ ] Claims, metrics, credentials, testimonials sourced/approved.
- [ ] Demo content removed or visibly labelled and approved.
- [ ] No placeholder copy or internal notes remain.

## Responsive
- [ ] 320px  [ ] 360px  [ ] 390px  [ ] 640px
- [ ] 768px  [ ] 1024px  [ ] 1280px+
- [ ] No horizontal overflow.
- [ ] Mobile menu and touch targets usable.
- [ ] Footer/section alignment reviewed.

## Functionality
- [ ] Navigation/anchors.
- [ ] Primary/secondary CTAs.
- [ ] WhatsApp/call/email links.
- [ ] Forms and privacy behavior.
- [ ] Selectors, accordions, and interactions.
- [ ] External links.

## Release
- [ ] Title, description, favicon, social preview.
- [ ] Image alt text.
- [ ] HTTPS and canonical domain.
- [ ] Client staging and release approvals.

# Client Media Request — Starter

Use this only after the discovery conversation, when the Media Readiness Summary shows that authentic visuals will materially improve the website. Keep it as a short, optional request; do not turn it into a second intake questionnaire.

## Message to client

Halo! Supaya website bisa benar-benar menampilkan bisnis dan layanan Anda (bukan hanya teks), boleh bantu kirim beberapa foto atau video yang sudah ada?

Yang paling membantu:
1. **Tempat usaha / suasana:** tampak depan, area kerja, interior atau suasana layanan.
2. **Produk atau layanan:** foto produk, kendaraan, hasil menu, ruangan, atau detail layanan yang paling sering dijual.
3. **Proses:** beberapa foto/video singkat saat layanan dikerjakan (bila relevan).
4. **Hasil nyata:** contoh pekerjaan/proyek/produk yang sudah selesai dan boleh ditampilkan.
5. **Tim atau pemilik:** opsional, hanya bila memang ingin ditampilkan.
6. **Identitas brand:** logo asli, kemasan, katalog, warna/brand guide bila tersedia.

Tidak perlu mengedit atau mendesain ulang. Kirim file asli dengan kualitas terbaik yang tersedia. Foto dari HP juga boleh. Kalau belum punya beberapa jenis foto, tidak masalah—kami akan catat dan tentukan alternatif yang aman.

Sebelum digunakan, mohon beri tahu:
- Foto/video tersebut dibuat atau dimiliki oleh siapa?
- Apakah boleh digunakan untuk website komersial dan materi promosi bisnis?
- Apakah orang yang terlihat sudah setuju untuk ditampilkan?
- Apakah ada logo, karya pihak lain, atau lokasi privat yang memerlukan izin tambahan?
- Apakah ada foto/video yang hanya boleh dipakai untuk referensi internal dan tidak boleh dipublikasikan?

Kami tidak akan menganggap file yang dikirim otomatis boleh dipublikasikan. Materi yang izinnya belum jelas tidak akan dipasang sampai dikonfirmasi.

## Operator notes (not sent as a second questionnaire)

Prioritize requests by actual section/customer question. Record each supplied file in the canonical Asset/Permission Register with source ID, creator/owner, intended use, permission, consent, publication status and source locator. Do not ask the client to provide a fixed number of assets if the website does not need them.

Never request private customer lists, identity documents, payment screenshots, passwords or unrelated personal material. Keep sensitive information out of the website project.

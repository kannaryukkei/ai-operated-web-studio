# Starter Client Workspace Template

Copy this folder into a private workspace for each Starter client.

1. Duplicate this folder to `client-[business-slug]-starter`.
2. Create a private repository if source versioning/handover is included.
3. Fill the project dashboard.
4. Complete discovery, scope, content, and approvals in sequence.
5. Follow `docs/starter-delivery-playbook.md`.
6. Use `prompts/starter/` for AI stage execution.

Folders: 00 project control; 01 discovery; 02 content; 03 scope; 04 design; 05 production; 06 QA; 07 launch; 08 retrospective.

Never store credentials, tokens, payment data, or private customer records here.

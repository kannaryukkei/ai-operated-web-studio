# Optional Content and Media Helpers

This folder contains optional working files for Starter projects where the number of assets or sections makes a separate record useful. It is not a project-management workspace, client questionnaire, required folder structure or approval workflow.

## Available helpers

- `content-asset-register.csv`: provenance, exact asset page/licence, rights/permission, proof class, crop and optimized local file. Use when multiple assets or rights decisions need tracking.
- `media-requirements.csv`: planned media, business purpose, page section, aspect ratio, crop and fallback. Use when the media plan is substantial.
- `media-client-request.md`: concise example-led request for missing authentic business media.
- `section-map.md`: optional section/content plan for complex pages; a simple site can be planned directly in its project conversation.

Do not create empty copies just because they exist. Do not use project dashboards, approval logs, stage checklists or mandatory record IDs. The project conversation is the working context.

Follow Master Skill v1.13 and the selected operating mode. In `client_service`, real facts and media permissions must be supported. In `studio_development`, synthetic assets may be used only as clearly labelled internal test content; no public release or production deployment.

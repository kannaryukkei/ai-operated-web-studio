# Prompt — Independent QA and Remediation

Act as independent QA. Review scope, content accuracy/demo labels, desktop/tablet/mobile layout, overflow, navigation, CTAs, forms, interactions, image crops/loading/credits/alt text, keyboard focus, semantics, contrast, reduced motion, metadata, build, console/network errors, security, privacy, and third-party dependencies.

Run automated tests and add targeted tests. Report severity, location, reproduction, expected/actual behavior, and fix. Fix authorized in-scope defects and re-run tests. Never claim visual review that was not performed.
